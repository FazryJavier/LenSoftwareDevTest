# US-005: Mengubah entitas

**Prioritas:** Must · **Kebutuhan:** FR-5, FR-7 · **Status:** Belum mulai

## Story

Sebagai **operator**, saya ingin mengubah data dan lokasi entitas, agar informasinya tetap sesuai dengan kondisi nyata.

## Kriteria penerimaan

1. **Diberikan** panel detail terbuka, **ketika** saya memilih "Ubah", **maka** form terisi data entitas saat ini.
2. **Diberikan** mode ubah, **ketika** saya mengklik peta atau mengetik koordinat, **maka** posisi marker dan nilai form berubah bersama.
3. **Diberikan** mode ubah, **ketika** saya menggeser marker, **maka** nilai koordinat pada form ikut berubah. *(dapat dipotong; lihat [PEP §3](../PEP.md#3-prioritas-bila-waktu-sempit))*
4. **Diberikan** data valid, **ketika** saya menyimpan, **maka** data dan marker diperbarui, serta `updated_at` berubah.
5. **Diberikan** saya membatalkan, **ketika** form tertutup, **maka** marker kembali ke posisi semula dan data tidak berubah.
6. **Diberikan** entitas sudah dihapus pihak lain, **ketika** saya menyimpan, **maka** UI menampilkan bahwa entitas tidak ditemukan.

## API

`PUT /api/v1/entities/{id}`. Semua field wajib dikirim; atribut yang tidak dikirim akan terhapus.

## Pengujian

- Unit backend: 200, 400, 404, dan 422.
- Integrasi: seluruh field terganti, `created_at` tetap, dan `updated_at` berubah.
- Unit frontend: pengisian awal form, pembatalan, dan pemetaan error.
- E2E: mengubah nama dan lokasi, lalu memastikan hasilnya bertahan setelah muat ulang.
