# US-003: Melihat detail entitas

**Prioritas:** Must · **Kebutuhan:** FR-3 · **Status:** Selesai

## Story

Sebagai **operator**, saya ingin membuka detail entitas dari peta, agar saya dapat membaca informasinya secara lengkap.

## Kriteria penerimaan

1. **Diberikan** marker pada peta, **ketika** saya memilihnya, **maka** panel detail menampilkan nama, jenis, status, deskripsi, atribut, koordinat, serta waktu dibuat dan diperbarui.
2. **Diberikan** panel detail terbuka, **ketika** saya memilih marker lain, **maka** panel menampilkan entitas tersebut.
3. **Diberikan** panel detail terbuka, **ketika** saya menutupnya atau menekan `Esc`, **maka** panel tertutup dan pilihan marker hilang.
4. **Diberikan** entitas terpilih sudah dihapus pihak lain, **ketika** detail dimuat, **maka** UI menampilkan pesan bahwa entitas tidak ditemukan.
5. **Diberikan** nilai berisi HTML, **ketika** detail ditampilkan, **maka** nilai tersebut tampil sebagai teks biasa dan tidak dieksekusi.

## API

`GET /api/v1/entities/{id}`.

## Pengujian

- Unit backend: 200, 404, dan 400 untuk UUID tidak valid.
- Unit frontend: isi panel, atribut kosong, status tidak ditemukan, dan nilai berisi HTML.
- E2E: memilih marker membuka panel detail.
