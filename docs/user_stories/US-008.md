# US-008: Filter jenis dan status

**Prioritas:** Should · **Kebutuhan:** FR-8 · **Status:** Selesai

## Story

Sebagai **operator**, saya ingin memfilter entitas menurut jenis dan status, agar saya dapat fokus pada objek tertentu.

## Kriteria penerimaan

1. **Diberikan** filter jenis atau status dipilih, **ketika** nilainya berubah, **maka** hanya entitas yang cocok tampil pada peta.
2. **Diberikan** filter jenis dan status sama-sama aktif, **ketika** data dimuat, **maka** entitas harus cocok dengan keduanya.
3. **Diberikan** filter aktif, **ketika** halaman dimuat ulang atau URL dibagikan, **maka** filter yang sama tetap berlaku.
4. **Diberikan** filter aktif, **ketika** saya menghapus filter, **maka** semua entitas pada area kembali tampil.
5. **Diberikan** nilai filter tidak valid pada API, **ketika** dikirim, **maka** API membalas 400.

## API

`GET /api/v1/entities?type=vehicle,facility&status=active`.

## Pengujian

- Unit backend: parsing nilai tunggal, banyak nilai, dan nilai tidak valid.
- Integrasi: kombinasi `type`, `status`, dan `bbox`.
- Unit frontend: sinkronisasi filter dengan URL.
