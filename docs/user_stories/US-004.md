# US-004: Menambah entitas

**Prioritas:** Must · **Kebutuhan:** FR-4, FR-7 · **Status:** Belum mulai

## Story

Sebagai **operator**, saya ingin menambah entitas dengan memilih titik di peta, agar lokasinya akurat tanpa mengetik koordinat.

## Kriteria penerimaan

1. **Diberikan** saya memilih "Tambah entitas", **ketika** saya mengklik peta, **maka** latitude dan longitude pada form terisi dan marker sementara tampil.
2. **Diberikan** form terbuka, **ketika** saya mengetik koordinat yang valid, **maka** marker sementara berpindah ke titik tersebut.
3. **Diberikan** data valid, **ketika** saya menyimpan, **maka** entitas tersimpan, marker tampil, dan pesan sukses muncul.
4. **Diberikan** data tidak valid, **ketika** saya menyimpan, **maka** tidak ada request yang dikirim dan pesan muncul pada field terkait.
5. **Diberikan** server menolak data, **ketika** respons 422 diterima, **maka** pesan server tampil pada field terkait dan isi form tidak hilang.
6. **Diberikan** request sedang berjalan, **ketika** saya menekan simpan lagi, **maka** tidak ada request tambahan.
7. **Diberikan** form berisi perubahan, **ketika** saya membatalkan, **maka** form dan marker sementara hilang setelah konfirmasi.

## API

`POST /api/v1/entities`.

## Pengujian

- Unit backend: 201 dengan header `Location`, 400, 415, dan 422.
- Integrasi: data tersimpan, termasuk koordinat `0,0` dan atribut.
- Unit frontend: skema Zod, pengisian koordinat, pemetaan error server, dan tombol nonaktif saat request berjalan.
- E2E: membuat entitas dari klik peta sampai marker tampil.
