# US-001: Fondasi aplikasi

**Prioritas:** Must · **Kebutuhan:** FR-1 · **Status:** Sedang dikerjakan. Jalur Docker Compose dan CI belum terbukti.

## Story

Sebagai **reviewer**, saya ingin menjalankan seluruh aplikasi dengan satu perintah, agar saya bisa menilai hasilnya tanpa konfigurasi manual.

## Kriteria penerimaan

1. **Diberikan** salinan `.env.example` sebagai `.env`, **ketika** saya menjalankan `docker compose up --build`, **maka** database, backend, dan frontend berjalan.
2. **Diberikan** aplikasi berjalan, **ketika** saya memanggil `GET /api/v1/health`, **maka** saya menerima 200 dengan envelope standar.
3. **Diberikan** database tidak dapat dijangkau, **ketika** saya memanggil `GET /api/v1/health`, **maka** saya menerima 503 tanpa detail internal.
4. **Diberikan** database kosong, **ketika** backend start, **maka** migrasi terpasang otomatis dan tabel `entities` tersedia.
5. **Diberikan** data sudah tersimpan, **ketika** container di-restart tanpa menghapus volume, **maka** data masih ada.
6. **Diberikan** skeleton sudah dibuat, **ketika** CI berjalan, **maka** job backend dan frontend lulus.

## Catatan implementasi

- Struktur folder mengikuti [ARCHITECTURE §2](../ARCHITECTURE.md#2-struktur-repository).
- Buktikan kombinasi versi pada [ITA §3](../ITA.md#3-hasil-cek-kompatibilitas) lewat instalasi dan build sungguhan.
- Script `package.json` wajib tersedia: `lint`, `lint:fix`, `format`, `format:check`, `typecheck`, `test`, `build`, `test:e2e`.
- Setel `platform: linux/amd64` pada service database, karena image PostGIS hanya tersedia untuk arsitektur itu.
- Semua service di Compose memiliki `healthcheck`, karena CI memakai `docker compose up --wait`.
- Tambahkan ekosistem `gomod` dan `npm` ke `.github/dependabot.yml`.
- Buat seed lokal, serta `backend/Dockerfile` dan `frontend/Dockerfile` (multi-stage, non-root).
- Buat database `geoentity_test` lewat script di `docker-entrypoint-initdb.d`, agar test integrasi lokal bisa berjalan.
- Terapkan aturan [CLAUDE.md](../../CLAUDE.md#aturan-agar-hasil-tidak-asal-jadi) ke tooling agar diperiksa otomatis:
  - `.golangci.yml`: `errcheck`, `govet`, `staticcheck`, `unused`, `ineffassign`, `errorlint`, `gosec`, `bodyclose`, `rowserrcheck`, `sqlclosecheck`, `noctx`.
  - ESLint: preset `strictTypeChecked`, `no-explicit-any`, `no-console`, dan aturan yang melarang impor MapLibre di luar `features/entities/map/`.
  - `tsconfig`: `strict` dan `noUncheckedIndexedAccess`.

## Pengujian

- Integrasi: migrasi berhasil pada database kosong.
- Handler: `/health` sehat dan tidak sehat.
- Manual: restart Compose dan pastikan data bertahan.
