# US-002: Menampilkan entitas pada peta

**Prioritas:** Must · **Kebutuhan:** FR-2 · **Status:** Selesai

## Story

Sebagai **operator**, saya ingin melihat entitas sebagai marker pada peta, agar saya tahu sebaran dan kondisinya sekilas.

## Kriteria penerimaan

1. **Diberikan** entitas tersimpan di area yang terlihat, **ketika** peta selesai dimuat, **maka** setiap entitas tampil pada koordinat yang benar.
2. **Diberikan** entitas berbeda jenis dan status, **ketika** marker tampil, **maka** jenis terlihat dari ikon dan status terlihat dari warna, tidak hanya dari warna saja.
3. **Diberikan** peta digeser atau diperbesar, **ketika** pergerakan selesai, **maka** daftar dimuat ulang dengan `bbox` area yang terlihat.
4. **Diberikan** jumlah entitas pada area melebihi 500, **ketika** data dimuat, **maka** UI memberi tahu pengguna untuk memperbesar peta.
5. **Diberikan** belum ada entitas, **ketika** peta dimuat, **maka** UI menampilkan pesan kosong. Ajakan menambah entitas menyusul bersama tombol tambah pada US-004.
6. **Diberikan** API gagal, **ketika** data dimuat, **maka** UI menampilkan pesan error dengan tombol coba lagi.

## API

`GET /api/v1/entities` dengan parameter `bbox`, `page`, dan `per_page`.

## Pengujian

- Unit backend: parsing `bbox`, `page`, dan `per_page`, termasuk nilai tidak valid.
- Integrasi: `bbox` hanya mengembalikan entitas di dalam area, dan latitude serta longitude tidak tertukar.
- Unit frontend: status loading, kosong, error, dan peringatan batas data.
- E2E: browser sungguhan dengan fixture API menampilkan marker, keadaan kosong, gagal, dan peringatan batas. Endpoint sungguhan diuji lewat proxy. Marker dari data sungguhan diuji mulai US-004, setelah `POST` tersedia.
