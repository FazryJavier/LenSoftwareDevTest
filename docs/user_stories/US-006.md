# US-006: Menghapus entitas

**Prioritas:** Must · **Kebutuhan:** FR-6 · **Status:** Sedang dikerjakan, menunggu CI

## Story

Sebagai **operator**, saya ingin menghapus entitas yang tidak lagi dipakai, agar peta hanya menampilkan data yang relevan.

## Kriteria penerimaan

1. **Diberikan** panel detail terbuka, **ketika** saya memilih "Hapus", **maka** dialog konfirmasi menampilkan nama entitas.
2. **Diberikan** dialog konfirmasi, **ketika** saya membatalkan, **maka** tidak ada request dan data tidak berubah.
3. **Diberikan** dialog konfirmasi, **ketika** saya mengonfirmasi, **maka** entitas terhapus, marker hilang, panel tertutup, dan pesan sukses muncul.
4. **Diberikan** penghapusan gagal, **ketika** respons error diterima, **maka** marker tetap ada dan pesan error muncul.
5. **Diberikan** entitas sudah dihapus pihak lain, **ketika** saya mengonfirmasi, **maka** UI memberi tahu bahwa entitas sudah tidak ada dan peta diperbarui.

## API

`DELETE /api/v1/entities/{id}`. Penghapusan bersifat permanen.

## Pengujian

- Unit backend: 200, 400, dan 404.
- Integrasi: baris terhapus, dan penghapusan kedua menghasilkan 404.
- Unit frontend: dialog konfirmasi, pembatalan, dan penanganan error.
- E2E: menghapus entitas dan memastikan marker hilang.
